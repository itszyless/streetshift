# Security and privacy

Do not post API keys in public issues. Restrict browser Google Map Tiles keys by API and HTTP referrer; monitor usage and configure billing alerts. Revoke accidentally exposed unrestricted keys in Google Cloud.

This app does not run a backend, create accounts, request device location or collect analytics. Explicit location searches go to Nominatim, nearby coordinates go to Overpass or the OSM map API, optional scenery requests/key go to Google, and Google Fonts supplies typography. Providers have their own privacy policies. Runtime keys stay in page memory.

For sensitive vulnerabilities, use GitHub private reporting if enabled or the maintainer's public contact method, without posting exploit details publicly.

# Included Vienna dataset

`vienna.json` contains roads and building ways from OpenStreetMap, retrieved 2026-10-21 from:

https://api.openstreetmap.org/api/0.6/map?bbox=16.368,48.204,16.380,48.212

https://opendatacommons.org/licenses/odbl/1-0/

Attribution and community copyright information: https://www.openstreetmap.org/copyright

This database is licensed separately from the application's MIT-licensed code. It is a filtered extract of mapped ways and their node coordinates. Rendering converts coordinates to a local approximation; mapped heights/levels are used when available, with estimated defaults otherwise. No Google imagery or tile data is included.
